1 ¿Cuántos usuarios están registrados en un evento específico?

annotate() + Count('registros')

Calcula la cantidad total de participantes registrados en cada evento mediante agregación en el QuerySet.

# Django ORM: Anotación y conteo de la relación inversa 'registros' eventos_con_conteo = Evento.objects.annotate( total_usuarios=Count('registros') ).select_related('organizador').order_by('-total_usuarios') # Para un evento específico: total_especifico = evento.registros.count()

filter(fecha__year, fecha__month)

# Django ORM: Filtrado temporal por año y mes en curso ahora = timezone.now() eventos_este_mes = Evento.objects.filter( fecha__year=ahora.year, fecha__month=ahora.month ).order_by('fecha') total_eventos_este_mes = eventos_este_mes.count()

3 ¿Quiénes son los usuarios más activos en términos de participación?

annotate() + order_by('-total')[:5]

Clasifica a los usuarios según el número de registros a eventos que poseen en orden descendente.

# Django ORM: Anotar cantidad de registros por usuario y ordenar de mayor a menor usuarios_mas_activos = Usuario.objects.annotate( total_participaciones=Count('registros') ).order_by('-total_participaciones')[:5]

4 ¿Cuántos eventos ha organizado un usuario en particular?

annotate(Count('eventos_organizados'))

Conteo de eventos creados por cada usuario a través de la relación de clave foránea inversa.

# Django ORM: Cantidad de eventos organizados por cada usuario usuarios_organizadores = Usuario.objects.annotate( total_organizados=Count('eventos_organizados') ).filter(total_organizados__gt=0).order_by('-total_organizados') # O para un usuario en específico: total_usuario = usuario.eventos_organizados.count()

5 Consultas Complejas con Q Objects (OR / AND / NOT)

from django.db.models import Q

Permite construir consultas SQL con operadores lógicos avanzados (| para OR, & para AND, ~ para NOT).

# Django ORM: Búsqueda flexible multicriterio con Q Objects consulta_q = Evento.objects.filter( (Q(titulo__icontains=q_busqueda) | Q(descripcion__icontains=q_busqueda)) & Q(capacidad__gte=30) ).distinct()

6 Estadísticas Globales del Sistema con aggregate()

aggregate(Avg, Max, Min, Sum, Count)

Calcula valores escalares resumen de toda la tabla de eventos directamente en la base de datos SQL.

# Django ORM: Agregación estadística en un solo query SQL estadisticas = Evento.objects.aggregate( total_eventos=Count('id'), promedio_capacidad=Avg('capacidad'), max_capacidad=Max('capacidad'), min_capacidad=Min('capacidad'), capacidad_total_combinada=Sum('capacidad') )
